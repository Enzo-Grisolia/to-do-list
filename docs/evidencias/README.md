# Evidências da atividade

Esta pasta deve conter as capturas de tela reais da execução do aplicativo, conforme o enunciado da FIAP.

Sugestão de nomes para manter a entrega organizada:

1. `01-lista-inicial.png` — tela inicial com a lista de tarefas.
2. `02-cadastro-nova-tarefa.png` — formulário preenchido para cadastro.
3. `03-tarefa-cadastrada.png` — nova tarefa aparecendo na lista.
4. `04-edicao-tarefa.png` — edição de uma tarefa existente.
5. `05-tarefa-concluida.png` — tarefa marcada como concluída.
6. `06-exclusao-tarefa.png` — evidência da exclusão.
7. `07-navegacao-formulario.png` — navegação entre lista e formulário.
8. `08-build-sem-erros.png` — build ou execução do projeto sem erros.

## Orientações

- Use imagens legíveis e sem cortes que escondam a funcionalidade demonstrada.
- Faça as capturas em um emulador ou dispositivo Android real.
- Após adicionar as imagens, atualize a seção **Evidências** do `README.md` principal para exibi-las diretamente.
- Não substitua evidências reais por mockups ou imagens geradas artificialmente.
